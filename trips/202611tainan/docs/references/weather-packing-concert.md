# A. 天氣與打包

## A-1. 台南／高雄 11 月下旬氣候

11 月是南台灣東北季風乾季的起點，**是一年裡最舒服的旅遊月份之一**：白天像初夏、入夜轉涼、幾乎不下雨。

| 項目 | 台南（11 月） | 高雄（11 月下旬 11/20–11/22） |
|---|---|---|
| 平均高溫 | 約 27–28°C（白天體感 24–32°C）✅ | 約 27°C（月初 29°C → 月末 26°C）✅ |
| 平均低溫 | 約 19–20°C（清晨 14–23°C）✅ | 約 20°C（月初 22°C → 月末 19°C）✅ |
| 日夜溫差 | **約 7–9°C**，清晨與入夜明顯轉涼 | **約 7°C**，入夜北風吹起體感再降 2–3°C |
| 降雨機率 | 低。11 月起進入乾季，月雨量僅約 20–30 mm ✅ | **約 8%**（全月幾乎不變）✅ |
| 濕度 | 明顯下降，乾爽 | 「悶熱日比例」由月初 83% 降到月末 41%，11/20–22 約 50–56% ✅ |
| 風 | 東北風轉北風，市區風不大 | **北風為主，平均風速 12.5–13 km/h** ✅ ← 露天體育場夜間關鍵 |
| 日照時數 | 約 11 小時，日落約 17:15 前後 | 約 11 小時 ✅ |
| 紫外線 | ⚠️ 南台灣 11 月晴天中午仍常到「高量級」（UVI 6–8），不可輕忽。出發前查中央氣象署 UVI 預報 | 同左 |

### 實務結論
1. **白天短袖就夠、入夜一定要外套。** 台南小吃行程多在騎樓與街邊，中午會熱到流汗。
2. **11/21 演唱會是最需要保暖的一段**：露天場館、19:00 開演、22:00 散場，散場當下氣溫約 **20–22°C**，加上北風＋久坐不動＋汗濕，體感會明顯低於數字。**薄羽絨或刷毛外套必帶**，不要只帶襯衫。
3. 降雨機率雖低，但 **戶外場館不能撐傘**（見 B-2），所以「輕便雨衣」是成本最低的保險，4 件一起帶。

- **世運大道當日 08:00 至隔日 01:00 實施交通管制，管制區內汽機車禁止通行及停放。**
- **場館自有停車場約 300 席，大型活動時常改作接駁／管制用途，等於不可用。**
- 官方建議：停外圍捷運站（**R16 左營站**、R13 凹子底站）轉乘捷運，或利用外圍捷運站臨停接送。
- 捷運 **R17 世運站 1 號出口步行 8–10 分鐘**到場館；散場捷運會加密到 3–5 分鐘一班。
- ❓ 本場是否有「高鐵左營站 ⇄ 世運主場館」免費接駁專車尚未公布（K-SPARK 場有，進場 15:00–19:00、散場 21:30–23:30）。

### 推薦時程（方案 B：兼顧周邊商品，最務實）

## B-5. 散場後會合的實務建議（⚠️ 這段最容易出事，請照做）

### 現實狀況
- 4 萬人同時散場，**手機訊號會嚴重壅塞 30–60 分鐘**，打電話、LINE 都可能發不出去。
- **世運大道管制到隔日 01:00，車子絕對開不到場館門口接人。**
- 場館周邊叫車（Uber／計程車）散場時等 40–60 分鐘是常態。

### 建議做法
1. **出發前就用紙本寫死會合點，不要靠現場溝通。** 推薦：
   - **首選：高鐵左營站（高雄市左營區高鐵路105號）1F 出口** — 捷運 R16 直達，從 R17 只要 1 站，站體大、好認、有廁所與超商可等待，車輛臨停接送動線成熟。
   - **次選：漢神巨蛋購物廣場（高雄市左營區博愛二路777號）** — 捷運 R14，散場人潮較分散；但要注意百貨 22:30 打烊。
   - ❌ **不要**約「場館 X 號門」——出口人海、指標不清、訊號斷、根本找不到人。
2. **約定明確時間窗，不是「散場後見」。**
   - 建議約 **23:00–23:15 在高鐵左營站 1F**。推算：22:00 散場 → 人潮疏散＋步行到 R17 約 25–40 分鐘 → 22:40 上捷運 → 22:45 到 R16 → 23:00 會合。
   - **約定「等到 23:45，還沒到就各自改走 Plan B」**（Plan B：演唱會者自行搭計程車回台南飯店，或 3 人在停車場原地等到訊號恢復）。
3. **訊號斷掉的備援**：
   - 手機「**簡訊 SMS**」比 LINE／網路可靠，事先說好：到定點就發一則簡訊。
   - 演唱會者手機在散場前保留 **30% 以上電量**（整場拍照錄影很耗電），**行動電源必帶**。
   - 3 人的車上，**一支手機保持靜音但螢幕常亮**，不要 4 支都在滑而錯過來電。
4. **接人司機的動線**：
   - 22:30 前就把車開到高鐵左營站附近**臨停接送區**或站內停車場等，**不要 22:50 才從市區出發**（周邊會全部塞死）。
   - 高鐵左營站有室內停車場，可先停好進站內等人，比在路邊繞圈安全。
5. **回程**：23:15 從左營出發，國道1號北上台南，深夜順暢約 **50–55 分鐘**，**約 00:15 回到台糖長榮酒店**。
   - ⚠️ 隔天 11/22 要開回台北，**請把 11/22 早上排得很鬆**（睡到自然醒、飯店吃早餐、中午前退房），不要排 09:00 的行程。
6. **出發前務必查一次**：高雄市政府交通局／警察局的 **BTS 演唱會交通疏運公告**（通常活動前 1–3 天發布），確認當天的交管範圍、接駁車與臨停接送點，**以官方公告為準覆蓋本文建議**。
