## 1. 台北 → 台南（11/20 週五 08:00 出發）

### 1-1 國道一號 vs 國道三號

| | **國道一號（中山高）** | **國道三號（福高／二高）** |
|---|---|---|
| 上路點 | 台北交流道（約 25K） | 木柵交流道（約 26K） |
| 下交流道 | **仁德交流道（約 336K）** → 東門路 → 中華東路三段 | 新化系統 → **台86 快速道路西行** → 台南東區；或續行至歸仁交流道 |
| 國道里程 | 約 **312 km** | 約 **315 km**（國3）＋台86 約 15 km（免費） |
| 順暢時車程 | 約 **3 小時 20 分–3 小時 40 分** | 約 3 小時 30 分–3 小時 50 分 |
| 車流特性 | 車多、大車多；**五股—林口、楊梅—新竹、台中系統—彰化系統**是常態瓶頸 | 車流較少、線形較彎（關西—大溪、南投段坡度大），中南部路段通常比國1順 |
| 服務區密度 | 湖口、泰安、西螺、新營（＋仁德休息站） | 關西、西湖、清水、南投、古坑、東山、關廟 |
| 過路費（小型車） | **約 NT$317** | **約 NT$320** |

**建議走法（週五上午 08:00 出發）**：
- **主線走國道一號**（里程最短、下仁德交流道直達飯店門口）。
- 08:00 從台北出發正好卡到北部上班尖峰尾巴（07:00–09:00 五股—林口北上為主，南下影響較小），**南下方向週五上午通常順暢**。
- 若出發前用 Google Maps／高公局 1968 看到台中系統—彰化系統紅色，改走 **國3 → 南投 → 古坑 → 新化系統 → 台86 西行 → 台南東區**，時間差不多但穩定。
- **不建議**週五上午繞西濱台61，紅綠燈與砂石車多，省不到錢也省不到時間。

**過路費算法（國道計程收費）**
> 小型車：**每日前 20 km 免費**；20–200 km 以 **1.2 元/km**；超過 200 km 以 **0.9 元/km**（長途折扣）。
> 台北→台南 312 km ≒ 180 km×1.2（216 元）＋ 112 km×0.9（101 元）＝ **約 317 元／趟**。
> 11/21 台南↔高雄來回（約 90 km）≒ **約 84 元**。
> **三天總過路費估約 NT$720**（317＋84＋317）。

### 4-1 場館資訊

|---|---|
| 場館 | 高雄國家體育場（世運主場館） |
| 地址 | **高雄市左營區軍校路 100 號**（位於世運大道與軍校路口） |

| R17 其他出口 | 2 號（煉油廠宿舍側）、3 號（高雄煉油廠／半屏山）、**4 號（左楠路東側）** |

### 4-2 演唱會日的停車＝基本上「不要想開進場館」

依 BLACKPINK（2025/10/18–19）、告五人（4/12）、K-SPARK（5/30）等前例，高雄市交通局的標準作業是：

| 措施 | 內容 |
|---|---|
| **世運大道** | **活動日 08:00–24:00 全段封閉**，禁止汽機車通行與停放，僅緊急車輛／工作車／接駁車可進 |
| **場館停車場** | 場館本身約 300 席，但**大型演唱會「絕不提供汽車停車位」**，會改作接駁區／工作車輛用途。2024 年就發生過「停車場管制惹怨」的新聞 |
| **周邊路邊停車** | **軍校路、海功路、翠華路**部分路段禁止臨停與上下客 |
| 機車臨停區 | 世運主場館西北側、軍校路西側、緯六路沿線（08:00–23:00） |
| **預估壅塞路段** | **左楠路、翠華路、軍校路、國道10號** |
| **官方建議改道** | 南北向 → 改走 **民族路、博愛路、高鐵路**；東西向 → 改走 **加昌路、新莊一路、水管路** |
| 免費接駁車 | 前例為「高鐵左營站／台鐵新左營站 ↔ 演唱會場」，**進場 14:30–18:30、散場 21:30–23:30** |
| 捷運疏運 | 散場時段**縮短班距至 3–5 分鐘** |

### 4-3 推薦的「3 人開車 + 1 人看演唱會」分工方案

#### ✅ 方案 A（最推薦）：把車停在左營高鐵站，全隊搭捷運分頭行動

```
12:00 台南出發（國1 南下）
13:00 抵達高雄，車停左營高鐵站周邊停車場
13:00–17:30 四人一起在高雄玩（捷運紅線很方便）
17:30 看演唱會的人：R16 左營 → R17 世運（2 站，約 5 分鐘）
      另外 3 人：繼續在左營／巨蛋／瑞豐夜市活動，車不動
19:00–22:00 演唱會
22:00–22:45 看演唱會的人步行到 R17 → 搭捷運回 R16 左營
22:45 三人把車開到高鐵左營站接人（或直接在停車場會合）
23:00 出發回台南，00:00 前回到飯店
```

**這個方案的好處**：完全避開場館周邊車陣、不用在黑暗中找人、3 個人也不用在車上乾等 3 小時。

| 停車選項（左營高鐵站周邊） | 地址 | 費率 |
|---|---|---|
| 高鐵左營站官方汽車停車場 | 高雄市左營區高鐵路 105 號 | **60 元/小時，每日上限 480 元** |
| 五都大中停車場（左營） | 高雄市左營區（高鐵站旁） | **30 元/小時，每日上限 180 元**（較划算） |
| 嘟嘟房高鐵左營站停車場 | 高雄市左營區站前北路 | 依現場牌價，通常 30–40 元/小時 |

> 以 13:00 停到 23:00 共 10 小時計：官方停車場 **480 元（上限）**，五都 **180 元**。

#### 方案 B（若堅持開車去接）：在 R17 世運站 4 號出口接人

- **4 號出口在左楠路東側**，**與場館方向（1 號出口）相反**，人潮少、車也容易靠邊。
- 但左楠路本身就是官方預估的壅塞路段，**22:00–23:00 仍可能動彈不得**。
- 若採此方案：約 **22:15 之後**再從遠處（例如新莊一路、加昌路方向）慢慢接近，不要提早卡進去。

#### ❌ 不要做的事
- 不要約在世運大道、軍校路正門口接人（08:00–24:00 封閉／禁止臨停）。
- 不要在 21:50 就把車開到場館附近等 —— 會卡死在管制線內。

### 4-4 散場要多久才能離開？

| 方式 | 從散場到抵達目的地 |
|---|---|
| **捷運紅線** | **35–45 分鐘**（含排隊進站） |
| 接駁公車（往高鐵左營站） | 25–40 分鐘 |
| **計程車／Uber** | **50–90 分鐘**（光排班就 30–45 分鐘起跳） |
| 步行到 800 m 外 | 12–20 分鐘 |
| **自駕從場館周邊脫身** | **抓 60–90 分鐘**才能真正上路 |

> 參考值：2023 年 Coldplay 場，高雄市府在 **1 小時內疏散近 9 萬人**，疏散效率是全台最好的，但「人疏散快」不等於「車出得去」。

### 4-5 備案：高雄捷運紅線末班車

| 項目 | 時間 |
|---|---|
| 紅線末班車 | **24:00（午夜）由兩端點站（南岡山、小港）發車** |
| R17 世運站 往小港方向末班 | 約 **23:40–23:55**（世運站在紅線北段，實際時刻請查 krtc.com.tw 或高雄捷運 e 帶著走 App） |
| R17 世運站 往岡山方向末班 | 約 **00:10–00:20** |
| 演唱會日特別營運 | 散場時段**班距縮短為 3–5 分鐘**；大型活動時可能**延長營運時間**，以現場車站資訊面板公告為準 |

> **結論**：演唱會 22:00 結束，走到 R17 約 15–25 分鐘、排隊進站 10–30 分鐘 → **23:00 前一定搭得上車**，末班車不是問題。真正的風險是「開車的人卡在車陣裡接不到人」，所以方案 A 遠優於方案 B。

**最壞情況備案**：看演唱會的人自行搭捷運到 **R16 左營站**（高鐵左營站），三人把車停在那邊等；若連捷運都趕不上，從場館叫車回台南約 1,200–1,600 元。

| **國道五號常態高乘載** | **每週日 15:00–20:00**，**北向**（宜蘭→台北），南港系統南向入口、蘇澳至頭城北向入口；小型車須載 **3 人（含駕駛與小孩）以上** | ❌ **不適用** —— 我們走國1／國3，完全不碰國5 |

> **一句話結論**：**11/22 台南→台北走國道一號或三號，沒有任何高乘載管制。** 4 個人也遠超過 3 人門檻，完全不用擔心。
